# P.S.Y. Trading Accounts (offline Android app)

Offline accounting app for P.S.Y. Trading Private Limited, Shankhamul-31, Kathmandu: sales, purchases,
returns, inventory (moving weighted-average cost), expenses with VAT classification, Nepal VAT monthly
reports, double-entry ledger with trial balance and balance sheet, Bikram Sambat dates, PDF/CSV exports,
automatic daily backups, safe restore, and financial-year closing/reopening.
